# Demo: bestanden en artifacts

Deze map is een demonstratie van de verschillende soorten bestanden en artifacts die in één
sessie gegenereerd kunnen worden — allemaal met dezelfde onderliggende data en hetzelfde
kleurenschema, zodat het overzicht blijft ondanks de verschillende formaten.

| Bestand | Formaat | Gemaakt met | Laat zien |
|---|---|---|---|
| [`Demo-Verslag.docx`](Demo-Verslag.docx) | Word | docx-js | Koppen, een opsomming, een tabel en een ingesloten afbeelding |
| [`Demo-Data.xlsx`](Demo-Data.xlsx) | Excel | openpyxl | Een maandbudget met live formules, valuta-opmaak en een native grafiek |
| [`Demo-Presentatie.pptx`](Demo-Presentatie.pptx) | PowerPoint | pptxgenjs | Vier dia's met een eigen visueel ontwerp en een bewerkbare, native grafiek |
| [`Demo-Rapport.pdf`](Demo-Rapport.pdf) | PDF | reportlab | Een rechtstreeks (niet-geconverteerd) opgebouwd rapport met tabel en grafiek |
| [`chart.png`](chart.png) | Afbeelding | matplotlib | Een diagram met een gevalideerd, kleurenblind-veilig kleursysteem |
| [`dashboard.html`](dashboard.html) | Web / artifact | HTML/CSS/JS | Een interactieve, thema-bewuste pagina (licht + donker) met dezelfde data live |

Alle documenten hergebruiken dezelfde onderliggende cijfers ("voorbeeldmogelijkheden per
bestandstype"), zodat je in één oogopslag ziet hoe dezelfde inhoud er in elk formaat uitziet.

Open `dashboard.html` lokaal in een browser (of bekijk 'm via GitHub Pages) voor de
interactieve versie.
